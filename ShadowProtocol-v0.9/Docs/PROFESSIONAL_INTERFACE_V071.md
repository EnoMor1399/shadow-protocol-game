# Shadow Protocol v0.7.1 — Professional Interface Pass

This pass makes the prototype read as one classified military command system instead of a collection of prototype widgets.

## Visual hierarchy
- Restrained charcoal/graphite surfaces with controlled Directorate red.
- Stronger panel edges, inset technical frames and corner registration marks.
- Higher-contrast typography and clearer primary/secondary information hierarchy.
- Consistent glass/command-console treatment across pre-match and in-match surfaces.

## Pre-match
- Refined Operations menu, mission strip and navigation hover states.
- Improved specialization cards and selected-role feedback.
- Polished 10-player Ready Room, roster rows, secure-session status and deployment cards.
- Improved tactical-planning frame and briefing hierarchy.

## Live HUD
- Cleaner top scoreboard and team-alive strip.
- Repositioned compass for separation from round state.
- Unified mission clock, tactical signature, alert and objective modules.
- Improved health, weapon/ammunition, prompts, kill feed and network telemetry.
- More readable tactical-device and phase/deployment overlays.

## Design rule
The UI intentionally avoids neon-heavy sci-fi styling. Red is reserved for classification, threat, active selection and hostile/critical information; neutral information remains graphite, white and tactical grey.
